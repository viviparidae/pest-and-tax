# pest-and-tax 🐛🌾

ラブデリック風のコミカルで少し切ない世界観でおくる、**スローライフ農園アドベンチャー × リアルタイム畑防衛ゲーム**です。

---

## 📄 ゲーム概要 (About)

ボロボロの道や橋が放置された財政難の村が舞台。  
プレイヤーは畑で作物を育てて売却し、得た資金で「防衛設備の強化」や「村への納税（インフラ復旧）」を行っていきます。  
住民たちの奇妙で愛おしい頼み事を解決しながら、村の復興と物語の真相を目指しましょう！

---

## 🎮 コアシステム (Core Mechanics)

### 1. ⏱️ リアルタイム畑防衛と「ハタケの安心タイマー」
* **シームレスな害虫襲来**: 昼夜を問わずリアルタイムで害虫がやってきて作物を狙います。
* **安心タイマー（耐久時間）**: 畑が無人で耐えられる時間が画面上に常に表示されます。
  * 防衛設備を設置・補給するとタイマーが延長！
  * 設備が壊されると急速に減少！
  * プレイヤーは「あと〇分遠出できるか」を計算しながら探索を行います。

### 2. 💸 経済サイクル（防衛投資 vs 納税）
作物を売って得た資金の使い道が攻略の鍵となります。
* **防衛設備に投資** ➔ 「耐えられる時間」が延び、より遠くへ探索可能に。
* **村へ納税（寄付）** ➔ ボロボロの道路や橋が復旧し、新しいエリア（マップ）が開放。

### 3. 🤝 住民の頼み事とストーリー進行
* 新しいエリアで出会う住民たちの悩み（サブクエスト）を解決することで、メインストーリーが進行していきます。

---

## 🔄 プレイの流れ (Game Loop)

1. **【作物を育てる・守る】** 畑の手入れをし、防衛設備を整える。
2. **【出荷・資金獲得】** 無事に守り切った作物を売ってお金を稼ぐ。
3. **【投資と探索】** 
   * タイマーを伸ばして離れたエリアへ遠征！
   * 納税して壊れた橋やトンネルを修復！
4. **【物語の進行】** 住民の頼み事を解決し、村の秘密を解き明かす。
